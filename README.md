# Fire Auth

A Flutter application that demonstrates Firebase Authentication with contract and invoice management features. The app is built using the BLoC state management pattern and integrates with multiple Firebase services such as Authentication, Cloud Firestore and Firebase Storage.

## Features

- Email sign in and sign up using **Firebase Authentication**
- Manage contracts and invoices stored in **Cloud Firestore**
- Upload assets with **Firebase Storage**
- Multi-language support using **easy_localization** (English, Russian and Uzbek)
- Calendar based filtering and search
- Saving favourite contracts and viewing history

## Getting Started

1. Install Flutter 3.8 or later.
2. Run `flutter pub get` to fetch dependencies.
3. Configure Firebase for your platform. The project already contains `firebase_options.dart` generated by the FlutterFire CLI.
4. Start a simulator or connect a device and run:

```bash
flutter run
```

## Project Structure

```
lib/
  core/        # reusable constants, helpers and utilities
  features/    # domain features (auth, contract, invoice, profile)
  ui/          # presentation layer and widgets
  firebase_options.dart  # Firebase configuration generated by FlutterFire
```

Each feature follows a clean architecture approach with `data`, `domain` and `presentation` layers. State is handled using the `flutter_bloc` package.

## Assets

All images, SVGs, fonts and translations are located under the `assets/` directory and registered in `pubspec.yaml`.
